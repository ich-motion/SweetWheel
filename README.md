========================================================================
  SWEET.WHEEL // LAUNCHER v2 — портативный лаунчер скриптов
  Стиль: Sweet Vanilla Cyberpunk · иконка 8-бит
========================================================================

УСТАНОВКА
- Один файл SweetWheel.exe (~70 МБ), .NET ставить не нужно.
- Положите exe в любую папку и запустите. При первом запуске рядом
  появятся: settings.json, папка Scripts со стандартными скриптами,
  Scripts\README_scripts.txt (подробно про каждый скрипт) и лог.
- Иконка — в трее у часов. Двойной клик — окно настроек.

РАБОТА
- Колесо: Ctrl + ~ (настраивается). Открывается вокруг курсора и
  запускает скрипт в папке, открытой в Проводнике. Клавиши 1–9, 0 или клик.
- Окно настроек: Ctrl + Alt + W (на любой раскладке).
- В конце каждого стандартного скрипта — окно итога: OK или «Отменить всё»
  (полный откат). Подробности — Scripts\README_scripts.txt.

ВИД КОЛЕСА (окно настроек -> «Вид колеса»)
- Палитры: Sweet Vanilla, Neon Mint, Graphite, Game Boy.
- Свои цвета: сектор, наведение, «опасный» слот, центр и плашки, текст —
  HEX #AARRGGBB или кнопка «…» (палитра Windows).
- Скругление углов секторов и центрального блока.
- Мини-превью колеса в окне меняется сразу; «Сохранить» — запомнить.

СВОИ СКРИПТЫ
- Кладите .ps1 / .bat / .cmd в папку Scripts — появятся в библиотеке.
- Слот колеса запоминает скрипт по «паспорту» (Id в шапке файла), поэтому
  переименование файла не ломает слот. Если файл пропал, слот не очищается,
  а помечается «файл не найден».

ОБНОВЛЕНИЯ
- Трей -> «Проверить обновления» (или кнопка «vX.Y.Z · обновления» в окне).
  Включено по умолчанию: тихая проверка при запуске, не чаще раза в сутки.
- Лаунчер сам скачивает новый exe с GitHub (ich-motion/SweetWheel),
  сверяет контрольную сумму, заменяет себя и перезапускается.
- Стандартные скрипты обновляются вместе с ним:
    не меняли     -> новая версия на месте (старая — в Scripts\_backup);
    меняли сами   -> ваша не трогается, новая — в Scripts\_updates, в
                     библиотеке кнопки «Заменить на новую» / «Оставить мою»;
    удалили       -> не возвращается.
- Свои скрипты, слоты, хоткеи и цвета обновление не трогает.
  Перед первым запуском новой версии старый settings.json копируется в .bak.

ЛОГ
- sweetwheel_error.log рядом с exe (трей -> «Открыть лог ошибок»).
  По каждому запуску скрипта: STARTED и FINISHED / FAILED с кодом выхода
  и временем. Больше 10 МБ — старый лог уходит в .old.log.
